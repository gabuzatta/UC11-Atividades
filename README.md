Entrega da Atividade 1 da UC 11
Aplicação de Leilões de produtos
O projeto em questão, é a realização da entrega da atividade Curricular para aprovação em máteria do Curso de desenvolvimento de Software do Senac, para nível técnico. Trata-se de um aplicativo de sistema de Leilões, onde o objetivo 
é cadastrar produtos e realizar a venda e um pequeno controle de estoque. 
As tecnologias utilizadas para desenvolvimento e uso são JavaScript e banco Mysql
